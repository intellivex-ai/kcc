## 2024-05-15 - Hardcoded Fallback Credentials in Admin Auth
**Vulnerability:** The application had hardcoded fallback credentials (`admin` and `kcc2024`) in `src/lib/admin-auth.js` for when environment variables (`VITE_ADMIN_USERNAME` and `VITE_ADMIN_PASSWORD`) were missing. This is a critical security vulnerability, as anyone could potentially gain admin access if the app was deployed without proper environment configuration.
**Learning:** Hardcoded fallback values for sensitive information, even when intended for local development, can easily find their way into production environments if configuration is missed. This represents a significant risk, especially for authentication mechanisms.
**Prevention:** Instead of using predictable, hardcoded fallback values for credentials, default to securely generated random values (e.g., using `crypto.randomUUID()`) when expected environment variables are absent. This ensures that even in misconfigured environments, unauthorized access is prevented by failing securely.
