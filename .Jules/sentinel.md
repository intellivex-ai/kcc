## 2024-05-18 - Hardcoded Admin Fallback Credentials
**Vulnerability:** The admin authentication library (`src/lib/admin-auth.js`) fell back to hardcoded default credentials (`admin` and `kcc2024`) if environment variables were missing or improperly configured.
**Learning:** Hardcoded default credentials create a severe security risk in production environments where the proper configuration of `.env` files may be overlooked. Falling back to a static known value permits trivial unauthorized access to administrative functions. Additionally, `crypto.randomUUID()` may crash in insecure contexts like non-HTTPS connections, which necessitates checking its availability and using a secure fallback.
**Prevention:** Instead of statically predefined default credentials, a random, dynamic string should be generated using `crypto.randomUUID` (when available) or `Math.random` as a fallback. This ensures the application remains inaccessible if configuration is missing, safely enforcing environment configurations.
