## 2026-03-07 - [Accessible Icon Buttons]\n**Learning:** Custom icon-only buttons (like mobile menu or theme toggles) must always use explicitly set `aria-label` attributes for screen readers, and when removing default focus outlines, explicitly set `focus-visible` utility classes to ensure the buttons remain fully keyboard navigable without compromising mouse-click aesthetics.\n**Action:** Always add `aria-label` and `focus-visible` utility classes when styling custom icon buttons to satisfy both visual and accessibility requirements.
