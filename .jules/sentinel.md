## 2024-05-18 - Hardcoded Admin Password Fallback
**Vulnerability:** A hardcoded admin password (`kcc2024`) was used as a fallback if the `VITE_ADMIN_PASSWORD` environment variable was missing. This exposed a valid credential if the application was deployed without proper environment configuration. Additionally, `changePassword` was broken due to a reference to `DEFAULT_CREDENTIALS` instead of `ADMIN_CREDENTIALS`.
**Learning:** Hardcoding credentials, even as fallbacks in an environment configuration block, is dangerous because it provides an easy backdoor if configuration is forgotten. Applications should fail securely when required secrets are missing, rather than quietly enabling insecure default access.
**Prevention:** Always ensure that missing environment variables for sensitive settings generate secure, random fallbacks or cause an immediate error (failing securely). For Vite apps, use `crypto.randomUUID()` with a non-crypto fallback (`Math.random().toString(36).substring(2)`) to ensure random strings are generated securely where possible, avoiding predictable hardcoded values.
