## 2025-04-02 - Hardcoded Admin Credentials Risk
**Vulnerability:** Hardcoded fallback credentials ('admin' and 'kcc2024') were present in the client-side admin-auth.js library, which meant that if environment variables were missing, the application would default to universally known, easily guessable credentials for administrative access.
**Learning:** Client-side authentication systems relying on environment variables (like Vite's import.meta.env) often implement hardcoded fallbacks to prevent errors during local development or when variables are missing, inadvertently deploying backdoors into production. Furthermore, referencing non-existent credential variables (like DEFAULT_CREDENTIALS instead of ADMIN_CREDENTIALS) creates reference errors that break intended flows like change password.
**Prevention:** Always implement a secure failure mechanism when expected environment credentials are missing (e.g., set to undefined or throw an initialization error) rather than providing valid fallback credentials. Admin authentication must explicitly require configuration, failing securely otherwise.
