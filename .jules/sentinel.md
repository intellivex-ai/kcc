## 2024-05-24 - Hardcoded Fallback Admin Credentials
**Vulnerability:** The application used hardcoded fallback values for admin credentials (`'admin'` and `'kcc2024'`) when the corresponding `VITE_ADMIN_USERNAME` and `VITE_ADMIN_PASSWORD` environment variables were missing.
**Learning:** In a client-side authentication setup using Vite environment variables, hardcoded fallbacks present a severe risk. If the `.env` configuration is omitted or fails to load in production, the application silently defaults to widely-known, weak credentials rather than securely denying access. This bypasses the intended environment-based security mechanism. Additionally, these hardcoded values are explicitly compiled into the JavaScript bundle, making them trivial to extract.
**Prevention:** Always design authentication mechanisms to "fail securely". If required environment variables are missing, the system should either refuse to build, refuse to start, or explicitly deny all login attempts rather than supplying a fallback. Do not include development or testing credentials in production-ready source code.
