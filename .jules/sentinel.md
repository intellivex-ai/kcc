## 2025-04-03 - Hardcoded fallback credentials and error handling
**Vulnerability:** The admin authentication system (`src/lib/admin-auth.js`) had hardcoded fallback credentials (`kcc2024` for password, `admin` for username) if the environment variables (`VITE_ADMIN_USERNAME`, `VITE_ADMIN_PASSWORD`) were missing. This exposes the admin dashboard if the environment is not set up correctly.
**Learning:** Admin authentication was implemented using fallback credentials, which breaks "fail securely". Without environment variables, the system defaults to weak, hardcoded credentials, providing unauthorized access. Additionally, there was a reference to a non-existent `DEFAULT_CREDENTIALS` in the `changePassword` function, leading to reference errors.
**Prevention:** Remove fallback credentials. Fail securely by ensuring the authentication process explicitly checks that environment variables exist and are properly configured before attempting authentication. Always validate the presence of secrets before use.
