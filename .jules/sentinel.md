## 2024-05-14 - Removed hardcoded fallback credentials from admin auth
**Vulnerability:** The admin authentication logic in `src/lib/admin-auth.js` had hardcoded fallback credentials (`'admin'` / `'kcc2024'`) that would be used if the environment variables (`VITE_ADMIN_USERNAME`, `VITE_ADMIN_PASSWORD`) were missing. This meant the admin panel could be bypassed with default credentials if the environment was misconfigured.
**Learning:** Hardcoded fallbacks for sensitive environment variables create a severe security risk. If an environment is built without the intended secrets, the application silently defaults to known, predictable values, enabling unauthorized access. It is better to "fail securely" and block access entirely than to gracefully degrade to insecure defaults.
**Prevention:** Never use the `|| 'default_secret'` pattern for authentication credentials, API keys, or encryption keys in environment variable assignment. Ensure authentication logic explicitly checks for the presence of configured credentials and returns a secure error (e.g., "Authentication is not configured") if they are missing.
