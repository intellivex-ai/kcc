## 2025-02-17 - Hardcoded Admin Credentials and Fail-Open Authentication Bypass
**Vulnerability:** The admin authentication library (`src/lib/admin-auth.js`) contained hardcoded fallback credentials (`'admin'` and `'kcc2024'`) that would be used if the expected environment variables were not set.
**Learning:** This is a severe security risk. Hardcoded fallback credentials can be easily discovered, and in situations where environment variables fail to load (e.g. misconfiguration in deployment), the application "fails open", allowing an attacker to log in with predictable credentials. The `changePassword` function also had a reference error to a nonexistent object, indicating the auth module might have been copied/pasted and unverified.
**Prevention:** Always "fail closed" for authentication. Do not provide default fallback credentials. Ensure that if required secrets (like usernames or passwords) are missing, the system denies access and logs an error, rather than granting access using predictable defaults.
