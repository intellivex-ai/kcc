## 2024-04-16 - Hardcoded Default Admin Credentials in Client Bundle
**Vulnerability:** Admin authentication library (`src/lib/admin-auth.js`) had hardcoded literal string fallbacks (`'admin'` and `'kcc2024'`) for the `import.meta.env` variables.
**Learning:** In client-side Vite projects, literal string fallbacks in `import.meta.env` expressions are permanently embedded in publicly readable build outputs. An attacker could inspect the generated JavaScript bundle to find the hardcoded fallback password, which could allow them to gain access to the admin dashboard if the environment variables weren't set correctly or were omitted in a deployment environment. The codebase also contained a reference error to a non-existent `DEFAULT_CREDENTIALS` object in `changePassword`.
**Prevention:** Never use literal string fallbacks for environment-based secrets in frontend code. Always implement a secure failure state that denies access (e.g., disables login) if the required environment credentials are not provided during the build.
