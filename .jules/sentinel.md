## 2024-10-30 - Fix Hardcoded Admin Credentials Fallback
**Vulnerability:** The admin authentication logic in `src/lib/admin-auth.js` was using hardcoded fallback credentials (`'admin'` / `'kcc2024'`) when environment variables `VITE_ADMIN_USERNAME` and `VITE_ADMIN_PASSWORD` were missing. This exposes a massive backdoor in case of misconfiguration or local development setups deployed insecurely.
**Learning:** Hardcoded credentials as fallbacks circumvent the intended environment-based security model. It is more secure for the app to crash or effectively "lock out" logins by using unpredictably random strings if credentials are not explicitly supplied. Furthermore, `crypto.randomUUID()` must be checked for existence because it is only available in secure contexts.
**Prevention:** Never use static strings as fallbacks for sensitive environment variables like API keys, secrets, or passwords. Either throw an error on startup, or use a secure random generator that effectively renders the credentials inaccessible.
