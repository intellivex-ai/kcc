## 2024-05-24 - Hardcoded Admin Credentials Fallback
**Vulnerability:** The application used hardcoded fallback credentials (`|| 'admin'` and `|| 'kcc2024'`) in `src/lib/admin-auth.js` if the environment variables for admin authentication (`VITE_ADMIN_USERNAME`, `VITE_ADMIN_PASSWORD`) were missing.
**Learning:** This design bypassed environment-based security protections by defaulting to easily guessable credentials. Also, if environment variables are meant to protect access, the application must be designed to fail securely when these variables are not present. Relying on default credentials to handle misconfigured environments introduces a critical security gap where any unconfigured instance guarantees unauthorized admin access. Furthermore, referencing non-existent properties (`DEFAULT_CREDENTIALS.password`) in fallback methods introduces unhandled runtime errors that can hinder administrative password recovery flows.
**Prevention:** Always fail securely by throwing an error or denying access when necessary security-related environment variables are missing. Do not use hardcoded default passwords for admin endpoints or access layers.
