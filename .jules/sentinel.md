## 2024-05-24 - [Critical Vulnerability: Hardcoded Admin Fallback Credentials]
**Vulnerability:** The admin authentication system (`src/lib/admin-auth.js`) contained hardcoded fallback credentials (`admin` / `kcc2024`) that activated automatically if production environment variables were missing or misconfigured. This effectively created an unauthorized backdoor into the administrative dashboard.
**Learning:** In a production-ready application, fallback mechanisms designed for development convenience (like default passwords) should never be deployed or implicitly trusted in the auth validation chain. A missing configuration should result in a secure failure (denial of service/access), not a fallback to a vulnerable state. Additionally, missing variable references (like the incorrect `DEFAULT_CREDENTIALS` usage) can cause unexpected application states.
**Prevention:** Always follow a "fail-secure" model. If environment variables governing authentication are missing, the system must outright reject login attempts. Avoid defaulting critical secrets. Utilize strong TypeScript or linting rules (with proper naming conventions) to catch missing/undefined credential references early.
