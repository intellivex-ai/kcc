## 2024-05-24 - Optimizing sequential `.filter()` operations
**Learning:** React dashboard components often implement multiple filtering criteria (e.g., searching text and filtering by category dropdowns) using consecutive array `.filter()` calls. This results in traversing the dataset multiple times (O(kN) complexity, where k is the number of filters). Additionally, doing string transformations like `searchTerm.toLowerCase()` directly inside the filter loop re-allocates memory and re-evaluates the same pure function for every single item in the array.
**Action:** Consolidate multiple filter passes into a single `.filter()` call containing early returns. Always hoist loop-invariant transformations (like `.toLowerCase()`) outside of iteration blocks. Add defensive checks against `undefined` or `null` strings to prevent runtime errors during matching.
