## 2025-04-03 - Consolidate sequential .filter() operations and cache loop-invariant values
**Learning:** In dashboard components with multiple sequential `.filter()` operations on arrays (like `students` or `inquiries`), each `.filter()` iterates over the entire intermediate array. For $k$ filters on an array of length $N$, this results in O(kN) runtime complexity. Additionally, performing string transformations like `toLowerCase()` inside the filter callback repeatedly evaluates the same expression on loop-invariant variables (e.g., `searchTerm`).
**Action:** Consolidate multiple filter conditions into a single `.filter()` pass. Calculate loop-invariant values (like `searchTerm.toLowerCase()`) outside the `.filter()` loop, utilizing safe fallback logic (`(searchTerm || '').toLowerCase()`) to avoid null or undefined errors.
