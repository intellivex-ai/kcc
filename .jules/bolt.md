## 2024-05-24 - Optimization of Sequential Filters in Dashboard Components
**Learning:** Dashboard components (like `Students.jsx` and `Inquiries.jsx`) previously implemented client-side filtering using multiple sequential `.filter()` array methods. This created an O(kN) algorithmic complexity (where k is the number of filters) that scaled poorly with large datasets, as the entire array was traversed multiple times. Additionally, string operations like `.toLowerCase()` were executed inside the loop on every iteration, causing unnecessary CPU overhead.
**Action:** Consolidate sequential `.filter()` operations into a single combined pass to reduce time complexity to O(N). Cache loop-invariant values (like lowercased search strings) outside the loop before mapping or filtering. When applying filtering logic, employ short-circuit evaluation (`return false` early) to minimize unnecessary object property access.
