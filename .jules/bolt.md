## 2024-03-24 - React Derived State and Rendering Loop Optimization
**Learning:** This codebase contained a widespread performance anti-pattern across admin and listing components (like `Inquiries.jsx` and `Students.jsx`) where derived filtering state was managed redundantly using `useEffect` + `useState`. Furthermore, `.toLowerCase()` string transformations were being invoked repeatedly inside array `.filter()` loops during renders, significantly increasing CPU overhead for large lists.
**Action:** Always hoist expensive static transformations (like `.toLowerCase()`) outside of array iteration loops. Use `useMemo` to compute derived data directly instead of syncing it to separate state variables with `useEffect`. This prevents unnecessary component re-renders and minimizes work inside the render loop.
