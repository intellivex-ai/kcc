## 2024-05-24 - Combine Array Filters and Cache String Operations in Dashboards
**Learning:** In dashboard components like `Students.jsx` and `Inquiries.jsx`, running sequential `.filter()` operations and repeatedly evaluating `searchTerm.toLowerCase()` inside the filter callback causes redundant O(N) loops and O(N*M) string operations (where M is average string length). This creates an architectural bottleneck on the frontend as the dataset grows.
**Action:** Consolidate sequential array iterations (like multiple `.filter()` calls) into a single combined pass, and strictly cache loop-invariant values (like `.toLowerCase()` on search terms or guarding against null/undefined with `(searchTerm || '').toLowerCase()`) outside the loop to reduce runtime complexity and prevent memory thrashing.
