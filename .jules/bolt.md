## 2024-05-15 - Consolidate Multiple Array Iterations and Cache Loop Invariants
**Learning:** Found an anti-pattern in dashboard components (`Students.jsx`, `Inquiries.jsx`) where multiple sequential `.filter()` operations were used to refine arrays based on user input (status/course and search term), causing O(kN) iteration complexity where `k` is the number of filters. Additionally, loop-invariant operations like `.toLowerCase()` on the search term and boolean checks (`courseFilter === 'all'`) were placed inside the loop body, meaning they were unnecessarily recomputed for every item in the dataset.
**Action:** Always combine sequential `.filter()` or `.map()` operations into a single combined pass. Identify static, loop-invariant computations (like `searchTerm.toLowerCase()` or boolean filter flags) and execute them exactly once outside the loop to improve rendering speed when filtering large datasets.
