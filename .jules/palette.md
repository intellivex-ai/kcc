## 2026-05-09 - Missing ARIA Labels on Icon Buttons\n**Learning:** The codebase extensively uses Lucide React for icon-only buttons (e.g., in `NotificationSystem.jsx`), which often lack `aria-label` attributes. This makes them inaccessible to screen readers.\n**Action:** Consistently check for and add these descriptive labels to ensure screen reader accessibility, specifically targeting `button` elements wrapping icons.
