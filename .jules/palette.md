## 2024-05-24 - Missing ARIA labels on dynamic icon-only bot UI elements
**Learning:** Found that custom highly interactive components like the Chatbot toggle and the send button lack accessibility labels, despite being visually distinct due to icons. Since the icon components (`<X>`, `<MessageCircle>`, `<Send>`) don't inherently provide screen reader context, relying on their visual indication alone leaves screen-reader users unable to determine the button's purpose, especially for dynamic states like the toggle button where the action changes between open/close.
**Action:** Ensure dynamic `aria-label` attributes are applied to elements that toggle state and lack visible text, correctly describing the action (e.g. `aria-label={isOpen ? "Close" : "Open"}`) rather than just generic labels. Always add `aria-label`s to any interactive element that only uses an icon for visual meaning.
